# 🎓 Hintify Professional - User Guide

## Welcome to Hintify Professional!

Your AI-powered learning platform with intelligent hints and instant feedback.

## 🚀 Getting Started

### First Time Setup

1. **Start the Application**
   ```bash
   cd hintify-professional
   make dev
   ```

2. **Open Your Browser**
   - Navigate to: http://localhost:8000
   - You should see the Hintify home page with a beautiful animated background

3. **Explore the Interface**
   - Navigation bar at the top
   - Theme toggle (🌙/☀️) in the top right
   - Main content area with sections

## 📚 Main Features

### 1. Take a Test

**How to Start:**
1. Click **"Take Test"** in the navigation bar
2. You'll see 4 subject cards:
   - 💻 **Technology** - Computer science and programming
   - 🔬 **Science** - Physics, chemistry, and biology
   - 🌍 **Geography** - World geography and landmarks
   - 📚 **General Knowledge** - History, culture, and more

3. Click on any subject card to begin

**During the Test:**

- **Question Display**
  - Question text at the top
  - 4 multiple choice options (A, B, C, D)
  - Question counter showing your progress
  - Difficulty badge (Easy/Medium/Hard)

- **Difficulty Switcher**
  - Three buttons at the top: Easy | Medium | Hard
  - Click to switch difficulty levels
  - Your progress resets when switching

- **Answer a Question**
  1. Click on one of the four options
  2. Selected option highlights in blue
  3. Click **"Submit Answer"** button
  4. Immediate feedback:
     - ✅ **Green** = Correct!
     - ❌ **Red** = Incorrect
  5. Detailed explanation appears below

- **Get a Hint**
  - Click **"Get Hint"** button before submitting
  - AI-powered hint appears to guide you
  - Hints don't reveal the answer directly
  - Use hints strategically!

- **Navigation**
  - **Previous** button - Go to previous question
  - **Next** button - Go to next question
  - **Question Grid** - Click any number to jump to that question
  - Grid shows status:
    - Gray = Not attempted
    - Blue = Answered
    - Green = Correct
    - Red = Incorrect

- **Keyboard Shortcuts**
  - `N` - Next question
  - `P` - Previous question
  - `S` - Submit answer
  - `H` - Get hint
  - `D` - Open difficulty menu

**Test Summary:**

After completing all questions:
- Total score displayed prominently
- Accuracy percentage
- Breakdown: Correct, Incorrect, Unanswered
- Visual progress bar
- Options to:
  - Try again (same difficulty)
  - Back to subjects (choose new subject)

### 2. Upload Documents

**Generate Questions from Your Own Materials!**

**How to Upload:**

1. Click **"Upload"** in the navigation bar
2. You'll see the upload interface with:
   - Subject selector dropdown
   - Drag & drop area
   - File browser button

3. **Select a Subject**
   - Choose which subject category for your questions
   - Technology, Science, Geography, or General Knowledge

4. **Upload Your File**
   - **Drag & Drop**: Drag a file onto the upload area
   - **Click to Browse**: Click the area to select a file
   - **Supported Formats**:
     - PDF (.pdf)
     - Word Documents (.docx)
     - PowerPoint (.pptx)
   - **Max Size**: 10MB

5. **Wait for Processing**
   - Progress indicator shows upload status
   - AI analyzes your document
   - Generates 45 questions automatically:
     - 15 Easy questions
     - 15 Medium questions
     - 15 Hard questions

6. **Success!**
   - Confirmation message appears
   - Questions saved to "My Questions"
   - Each question includes:
     - 4 multiple choice options
     - AI-generated hint
     - Detailed explanation

**Tips for Best Results:**
- Use documents with clear, educational content
- PDFs with text (not scanned images)
- Well-structured documents work best
- Longer documents = more context for AI

### 3. My Questions

**View and Test Your Uploaded Questions**

**How to Access:**

1. Click **"My Questions"** in the navigation bar
2. See all your uploaded documents grouped by filename
3. Each document shows:
   - Document name
   - Upload date
   - Number of questions generated
   - Subject category

**Take a Test:**
- Click **"Start Test"** on any document
- Same test interface as curated questions
- All 45 questions available
- Switch between Easy/Medium/Hard
- Get hints and explanations

**Manage Questions:**
- View all questions from a document
- Edit questions (if needed)
- Delete documents you no longer need

### 4. Analytics

**Track Your Learning Progress**

**How to View:**

1. Click **"Analytics"** in the navigation bar
2. See comprehensive performance data

**Available Charts:**

- **Performance by Subject** (Bar Chart)
  - Compare your scores across subjects
  - Identify strengths and weaknesses
  - Focus on subjects needing improvement

- **Difficulty Distribution** (Doughnut Chart)
  - See how you perform at each difficulty
  - Easy vs Medium vs Hard breakdown
  - Percentage of questions at each level

- **Accuracy Trends** (Line Chart)
  - Track improvement over time
  - See your learning curve
  - Identify patterns in performance

- **Topic Heatmap** (Grid)
  - Visual representation of topic mastery
  - Color-coded performance indicators
  - Spot knowledge gaps quickly

**Key Metrics:**
- Total tests taken
- Average accuracy
- Average time per question
- Strongest subject
- Areas for improvement

**Export Reports:**
- Download charts as PNG images
- Save reports as PDF
- Share your progress

## 🔧 Troubleshooting

### Common Issues

**Problem: Questions not loading**
- Solution: Refresh the page
- Check internet connection
- Verify server is running

**Problem: Upload fails**
- Solution: Check file size (max 10MB)
- Verify file format (PDF/DOCX/PPTX)
- Ensure file is not corrupted

**Problem: Hints not appearing**
- Solution: Check AI provider configuration
- Fallback mode should work without API key
- Refresh and try again

**Problem: Theme not saving**
- Solution: Check browser localStorage
- Clear cache and try again
- Ensure cookies enabled

## 🚀 Advanced Features

### AI Provider Configuration

**For Advanced Users:**

Configure AI provider in `.env` file:

```bash
# Use OpenAI
AI_PROVIDER=openai
AI_API_KEY=sk-your-key
AI_MODEL=gpt-3.5-turbo

# Use DeepSeek
AI_PROVIDER=deepseek
AI_API_KEY=your-key
AI_MODEL=deepseek-chat

# Use Fallback (no API key)
AI_PROVIDER=fallback
```

**Benefits:**
- Better hint quality with AI
- More natural explanations
- Adaptive difficulty
- Personalized feedback
